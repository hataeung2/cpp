### Common rules for the three `main.cpp`
Same as 070-11 ([plan](/docs/tasks/feature_070-11-essentials-syntax/plan.md) "Common rules"): header block, English output, Korean comment line followed by its English line, anonymous namespace, camelCase functions, `kPascalCase` constants, `snake_case_` members, `[[nodiscard]]`, no `using namespace` at file scope (`using namespace std::chrono_literals;` inside a function is fine), exact includes, no platform `#ifdef`, exit code 0, section headings `== N. <name> ==` with no blank line between sections. ### `09_chrono_time` (`chrono_time`), `uses = ["lib:atugcc/core/timestamp.hpp"]`, `tags = ["chrono", "format"]`
`namespace chr = std::chrono;` (alias), `using namespace std::chrono_literals;` inside `main`.
1. `== 1. durations ==`: `duration_cast<seconds>(1500ms) = 1s`, `round<seconds>(1500ms) = 2s`, `duration_cast<seconds>(-1500ms) = -1s`, `floor<seconds>(-1500ms) = -2s`, `1h + 30min = 90min` (durations printed with `std::format("{}")`).
2. `== 2. clocks ==`: `steady_clock` around `std::this_thread::sleep_for(20ms)`: `elapsed >= 20ms: true` and `elapsed (rounded) = Nms` (varies, README says so); `steady_clock::is_steady = true`, `system_clock::is_steady = false`.
3. `== 3. calendar ==`: `2024-02-29 ok() = true`, `2023-02-29 ok() = false`, `2026y/February/last = 2026-02-28`; `2026-01-31 + months{1}` printed with `{}` (both libraries print `2026-02-31 is not a valid date`) and `ok() = false`, then the fix `year/month/last` → `clamped to 2026-02-28`; `weekday of 2024-02-29 = Thursday` (`{:%A}`); `days from 2026-11-03 to 2026-12-25 = 52`.
4. `== 4. time zones ==`: `constexpr`-built instant `sys_days{2026y/November/3} + 9h` printed as `instant (UTC): 2026-11-03 09:00:00`; for `UTC`, `Asia/Seoul`, `America/New_York`, `Europe/Berlin`: `std::format("{:%F %T %z}", zt)` and `zt.get_time_zone()->name()` (spec Assumption 5a: no `%Z`, no `operator<<`). `locate_zone` failure (`std::runtime_error`) prints `time zone database unavailable: <zone>` and continues. Then `America/New_York` local `2026-03-08 02:30`: catch `chr::nonexistent_local_time` (before any `runtime_error` handler; it derives from it) → `2026-03-08 02:30 America/New_York: nonexistent local time`, then `choose::earliest` → `2026-03-08 03:00:00 -0400`.
5. `== 5. format and parse ==`: `{:%F %T}` of the instant, `{:%A}` of its weekday (`Tuesday`), `{:%j}` (`307`), `hh_mm_ss{3725s}` (`01:02:05`). `std::istringstream in{"2026-11-03 09:00"}; chr::sys_time<chr::minutes> parsed; in >> chr::parse("%F %R", parsed);` → `parse ok: true`, `parsed == instant: true` (only a valid string; spec §4). Then the two "now" lines: `current_zone: <name>` (in a `try`, `std::runtime_error` → `current_zone: unavailable`) and `TimeStamp::str(): <text>` (`core::TimeStamp::str(static_cast<core::TimeStamp::OptFlags>(core::TimeStamp::Option::WithFmt))`).

### `10_filesystem_paths` (`filesystem_paths`), `uses = ["lib:atugcc/core/error.hpp", "lib:atugcc/core/memory_dump.hpp"]`, `tags = ["filesystem", "error"]`
`namespace fs = std::filesystem; namespace core = atugcc::core;` `constexpr std::string_view kSandbox = "fs_sandbox";`. Every printed path uses `generic_string()` (spec Assumption 8); paths inside the sandbox are printed relative to it (`lexically_relative`).
1. `== 1. paths ==`: `fs::path p = fs::path{"logs"} / "2026" / "app.log";` → `p = logs/2026/app.log`, `filename() = app.log`, `stem() = app`, `extension() = .log`, `parent_path() = logs/2026`, a copy with `replace_extension(".bak")` → `logs/2026/app.bak`; then the only OS-dependent line `preferred_separator = '\'` / `'/'` (`static_cast<char>(fs::path::preferred_separator)`).
2. `== 2. create a sandbox ==`: `fs::remove_all(box)` then `fs::create_directories(box / "logs" / "old")`; write three files in **binary** mode (sizes must match on Windows, no newline translation) inside one block, closed explicitly and checked with `fail()` after closing (a failed write prints `cannot write the files in fs_sandbox`, removes the sandbox with the `error_code` overload and exits 1), so sizes are read only from closed files: `a.txt` = `"hello"` (5), `logs/app.log` = `"line1line2"` (10), `logs/old/app.1.log` = `"old"` (3). Print `created fs_sandbox with 3 files`.
3. `== 3. list the sandbox ==`: `directory_iterator` over `box`: collect `[dir]  logs` / `[file] a.txt (5 bytes)` lines, sort, print. Then `recursive_directory_iterator`: collect `depth N: <relative path>` plus ` (K bytes)` for files, sort by path, print. Order is unspecified, hence sorting (spec Assumption 8; exercise 1).
4. `== 4. errors ==`: (a) `fs::file_size(box / "missing.txt")` in `try`, catch `const fs::filesystem_error& e` → `filesystem_error, path1 = fs_sandbox/missing.txt`; (b) `std::error_code ec; auto size = fs::file_size(missing, ec);` → `error_code: no_such_file_or_directory = true, returned (uintmax_t)-1 = true`; (c) `[[nodiscard]] core::Expected<std::uintmax_t> fileSize(const fs::path& path)` (error_code overload; failure → `std::unexpected(core::CoreError::FileIOFailure)`): `fileSize(a.txt) -> 5`, `fileSize(missing.txt) -> error FileIOFailure` (`core::to_string`), and `fileSize(missing).or_else([](core::CoreError) -> core::Expected<std::uintmax_t> { return 0; })` → `fileSize(missing.txt).or_else(0) -> 0`; an `and_then` step `requireNonEmpty` (`0` bytes → `InvalidArgument`) chained after `fileSize(a.txt)` → `-> 5`.
5. `== 5. timestamps and cleanup ==`: `auto ft = fs::last_write_time(box / "a.txt"); auto sys = std::chrono::clock_cast<std::chrono::system_clock>(ft);` → `modified (UTC date): <%F>` (varies by day, README says so), (no `to_sys` comparison: MSVC's `file_clock` has only `to_utc`, found at the first MSVC build; a comment says why `clock_cast` is the portable form), `modified within the last minute: true`; then `const auto removed = fs::remove_all(box);` → `remove_all removed 6 entries` (3 files, 2 directories, the sandbox), `fs_sandbox exists: false`.

### `13_lock_free_buffer` (`lock_free_buffer`), `uses = ["lib:atugcc/core/detail/thread_log_buffer.hpp", "lib:atugcc/core/ring_buffer.hpp"]`, `tags = ["lock_free", "thread", "performance"]`, `[run] profile = "long"`, `timeout = 120`
Standard library only. `struct Item { std::uint32_t producer; std::uint64_t seq; };` `constexpr std::size_t kCacheLine = 64;` (spec §2.4), `constexpr auto kRunTime = std::chrono::milliseconds{300};`, `constexpr std::size_t kCapacity = 1024;`, `constexpr int kProducers = 4;`.
- `template <typename T, std::size_t N, bool Padded = true> requires (std::has_single_bit(N) && std::is_trivially_copyable_v<T>) class SpscRing`: `[[nodiscard]] bool tryPush(const T&)` (producer only: `tail_` relaxed load, `head_` acquire load, full when `tail - head == N`, write `slots_[tail & (N - 1)]`, `tail_.store(tail + 1, release)`); `[[nodiscard]] bool tryPop(T&)` (consumer only: mirror). Members `alignas(Padded ? kCacheLine : alignof(std::atomic<std::size_t>)) std::atomic<std::size_t> head_{0};` and the same for `tail_`; `alignas(kCacheLine) std::array<T, N> slots_{};` `static_assert(std::atomic<std::size_t>::is_always_lock_free);` Indices grow without wrapping (unsigned overflow is defined and far away) and are masked on access. Comments on the release/acquire pair (happens-before for the slot contents), why full is `tail - head == N`, why `alignas`.
- `template <typename T, std::size_t N> class MutexQueue`: `std::mutex`, `std::array<T, N>`, `head_`/`tail_` as plain `std::size_t` guarded by the mutex; same `tryPush` / `tryPop`.
- `struct CaseResult { std::string_view name; int producers; std::uint64_t items; double itemsPerSecond; bool verified; };`
- `template <typename Push, typename Pop> [[nodiscard]] CaseResult runCase(std::string_view name, int producers, Push push, Pop pop)`: `push(int producer, const Item&) -> bool` is called by producer `producer` only, `pop(Item&) -> bool` by the consumer only. `std::vector<std::uint64_t> produced(producers)` (each producer writes its own element after its loop; read after join); consumer keeps `std::vector<std::uint64_t> nextSeq(producers)` and `consumed`, `ordered` (each item's `seq` must equal `nextSeq[producer]`, then `++`). Producers: `std::jthread` with `std::stop_token`; loop `while (!st.stop_requested())`: `if (push(i, Item{i, seq})) ++seq; else std::this_thread::yield();` Consumer: `std::jthread`; loop: pop → check; else if `st.stop_requested()` → drain until pop fails, then break; else `yield()`. Main: start consumer, start producers, `t0 = steady_clock::now()`, `sleep_for(kRunTime)`, request stop and join **producers first**, then stop and join the consumer (spec §4), `elapsed` from `t0`. `verified = ordered && consumed == sum(produced)`; items = consumed; items/s = consumed / elapsed seconds.
- Cases (heap-allocated queues, `std::make_unique`): (1) `mutex queue 1:1`, (2) `SPSC 1:1`, (3) `SPSC 1:1, false sharing` (`Padded = false`), (4) `mutex queue 4:1`, (5) `SPSC per producer 4:1` (`std::array<std::unique_ptr<SpscRing<…>>, kProducers>`, pop polls the rings round-robin from a rotating start).
- Output: one heading `== lock-free buffer: 5 cases, 300 ms each ==` (the cases are rows, not sections), a table header `{:<32} {:>9} {:>12} {:>14} {:>9}` (`case`, `producers`, `items`, `items/s`, `verified`) and one row per case (`items/s` as an integer, `verified` = `ok` / `FAILED`); rows 4 and 5 get ` (oversubscribed: N cores)` when `std::thread::hardware_concurrency()` is below 5 (spec §4). Last line `all cases verified: true`. Exit code 1 if any case is not verified (the smoke test then fails).
