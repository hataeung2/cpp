### `tools/practice.py` (spec §2.1, §2.2, Assumptions 3, 4, 6, 7, 8, 13)
- Constants: `PRACTICE_DIR = "practice"`, `STATE_FILE = "practice/state.json"`, `BACKUP_DIR = "practice/backup"`, `KEEP_BACKUPS = 10`.
- `practice_path(origin: str) -> str` (`lessons/...` → `practice/lessons/...`), `origin_path(path) -> str` (inverse), both repo-relative POSIX; anything else → `ValueError`.
- `Workspace(root: Path)`: loads the lesson catalog with `lessons.load(root)` on every call (`import lessons` from `tools/`; the server has loaded it under that name already, so one module).
  - `lesson_files(lesson_id) -> list[str]`: `lesson.toml` + `sources` (origin paths). `unit_ids(lesson_id)`: units that exist, in `resolve_uses(lesson.uses)` order. `status_all()`: every lesson with copies plus `orphans` (recorded copies whose lesson or unit is gone, `missing-origin`).
  - `start(lesson_id) -> dict`: copy every missing file (bytes, `shutil.copyfile` keeps line endings), record `baseSha` = sha256 of the origin bytes; existing copies untouched (an existing copy the state does not record is recorded with the current origin sha); then `status(lesson_id)`.
  - `status(lesson_id) -> dict`: first `follow()`: for every recorded file whose copy sha == baseSha and origin sha != baseSha, copy the new origin, update baseSha; manifests (`lesson.toml`, `unit.toml`) always follow; a source added to the origin manifest is copied, a source dropped from it is moved to a backup folder and forgotten. Then per file `state` ∈ `same` | `modified` | `both` (and `missing-origin` when the origin file is gone). Return shape of spec §2.1: `{lesson, dir, files: [{path, origin, state}], units: [{id, dir, files: [...]}]}`.
  - `reset(lesson=…|unit=…|path=…) -> dict`: the files of the scope whose copy differs from the origin are copied into `practice/backup/<YYYYMMDD-HHMMSS>[-n]/<practice path>` first, then the origin is copied over the copy and baseSha set; backups beyond the newest 10 folders are removed. Returns `{reset: [paths], backup: "<folder>" | null}`. A lesson reset never touches unit copies.
  - `state.json`: `{"version": 1, "files": {"<practice path>": {"origin": "...", "baseSha": "..."}}}`, written with a temp file + `os.replace`. Unreadable or wrong version → renamed `state.json.broken-<YYYYMMDD-HHMMSS>`, and every existing copy is re-recorded with the current origin sha (so it reads as `modified` if it differs; spec §4) — copies are never deleted.
  - `is_manifest(path)`: basename `lesson.toml` or `unit.toml`.
- CLI `main(argv)`: `start|status|reset|path` (spec §2.1), exit 0 / 1 (error) / 2 (arguments). Printed paths are repo-relative.

### Server (spec Assumptions 11, 12)
- `files.py`: writable = (`lessons/…` existing file, or new file with the allowed suffix — unchanged) or (`practice/lessons/…` existing file whose name is not `lesson.toml` / `unit.toml`). `practice/state.json`, `practice/backup/…`, new files under `practice/` → not writable (403). The symlink check of `lessons/` applies to `practice/lessons/` too.
- `server.py`: `GET /api/practice?lesson=<id>` → `status`; `POST /api/practice/start {lesson}` → `start`; `POST /api/practice/reset {lesson}|{unit}|{path}` (exactly one) → `reset`. Unknown lesson/unit → 404, a path that is not a practice copy → 400. Calls hold `files.write_lock`. `POST /api/runs` takes `practice: bool` (default false; not a bool → 400).
- `runner.py`: `LessonInfo` gets `practice: bool = False`; `RunManager.create(…, practice=False)`: with practice, `Workspace.start(id)` first, then the info with `path` = practice lesson folder and `practice=True`. `_build` target `practice_<id>` or `lesson_<id>`; default `executable`: `bin/practice/practice_<id>` or `bin/lessons/lesson_<id>`. `test_server.py` runs the fixture through `executable`, so a practice run test checks the target name in the build argv (with `build=False`, the argv is not run: the test checks `_build` through a stubbed `_stream` or the `phase` events) — the exact seam is chosen in U5 and named in its prompt.

### Frontend (spec Assumptions 9, 10, 11, 14)
- `practice.ts` (new, no DOM): `type Mode = 'practice' | 'original'`; `loadMode()/saveMode()` (`atugcc.mode`, try/catch, default practice); `toPractice(path)`, `toOrigin(path)`; `practiceFiles(lesson, status)`: the lesson's sources and the unit files mapped to practice paths, `lib:`/`mod:`/`test:` files and READMEs unchanged.
- `api.ts`: `practiceStatus(id)`, `practiceStart(id)`, `practiceReset(scope)`, `startRun(id, options)` with `practice`.
- `main.ts`: mode switch in the top bar (`index.html`: `<select id="mode">` or two buttons); `selectLesson` in practice mode calls `practiceStart`, then `editor.showFiles(mapped)`; units likewise (`selectUnit` maps the unit's files when a copy exists, else original read-only); README stays the origin (read-only in practice mode); Run sends `practice`; reset dialog (list of modified files, backup line after); Run disables reset.
- `editor.ts`: per tab a state from the last status (`modified` ●, `both` ⚠); in practice mode two small buttons in the tab bar for the active tab: ↺ (reset this file) and "비교" (Monaco `createDiffEditor` in the dialog, original model read-only from `api.readFile(origin)`, modified = the tab's model); after a reset the tab reloads from disk.
- `lessonTree.ts`: a mark on lessons/units with a modified copy (from a `practiceSummary` map that main.ts fills from the statuses it has fetched).
- `theme.css`: `.mode-original` warning colour on the top bar and tabs.
- `i18n.ts`: every new string in ko and en.
- Timings "previous run" key: the lesson id in original mode (as today), `${lessonId}:practice` in practice mode.

#### Frontend interfaces (shared by U7–U10)
- `practice.ts`: `type Mode = 'practice' | 'original'`; `MODE_KEY = 'atugcc.mode'`; `loadMode(): Mode` (storage error or unknown value → `'practice'`); `saveMode(mode)` (errors ignored); `toPractice(path)` (`lessons/…` → `practice/lessons/…`, anything else unchanged); `toOrigin(path)` (inverse, anything else unchanged); `isPracticePath(path)`; `type FileState = 'same' | 'modified' | 'both' | 'origin-changed' | 'missing-origin'`; `interface PracticeFile { path; origin; state }`; `interface PracticeStatus { lesson; dir; files: PracticeFile[]; units: { id; dir; files: PracticeFile[] }[] }`; `stateMap(status): Map<string, FileState>` (practice path → state, lesson and unit files); `practiceFiles(paths, status): string[]` (each path that has a copy in `status` → its practice path; others, e.g. `include/…`, `tests/…`, READMEs, unchanged; order kept); `changedFiles(status): PracticeFile[]` (state `modified` or `both`).
- `api.ts`: `practiceStatus(lesson)`, `practiceStart(lesson)` → `PracticeStatus`; `practiceReset(scope: { lesson: string } | { unit: string } | { path: string })` → `{ reset: string[]; backup: string | null }`; `RunOptions.practice?: boolean`.
- `editor.ts` (U9): `setOriginalWritable(on: boolean)` (off: every `lessons/…` tab is read-only 🔒 and never saved; practice mode); `setPracticeStates(states: Map<string, FileState>)` (tab class `practice-modified` for `modified`/`both`, `⚠` prefix and a title for `both`); `onActiveChange: (path: string | null) => void`; `reloadFromDisk(paths: string[])` (replace those tabs' content and sha from disk, dropping unsaved edits — used after a reset); `openDiff(host: HTMLElement, originPath: string, practicePath: string): Promise<() => void>` (Monaco diff editor in `host`: original model read-only from `api.readFile(originPath)`, modified = the open tab's model of `practicePath` (loaded if needed), `renderSideBySide`, theme as the editor; returns a dispose function).
- `lessonTree.ts` (U10): `setPracticeMarks(lessons: Set<string>, units: Set<string>)` → a `✎` badge (title from i18n) on those items; kept across `render` calls.
- `index.html` (U8): top bar `<select id="mode">` (two options, labels from i18n) after the theme button group; in the editor column above the tabs a small bar `<div id="practice-bar">` with `<button id="reset-file">`, `<button id="diff-file">`, `<button id="reset-lesson">` and a status `<span id="practice-note">`.
- `i18n.ts` keys (U10; ko and en): `mode.practice`, `mode.original`, `mode.title`, `practice.resetFile`, `practice.resetFileTitle`, `practice.diff`, `practice.diffTitle`, `practice.resetLesson`, `practice.resetLessonTitle`, `practice.originChanged`, `practice.both`, `practice.modified`, `practice.startFailed` (`{error}`), `practice.resetDone` (`{count}`, `{backup}`), `practice.resetNothing`, `practice.readOnlyOriginal`, `dialog.resetTitle`, `dialog.resetBody` (`{count}`), `dialog.resetConfirm`, `dialog.diffTitle` (`{path}`), `dialog.close`, `tree.practiceModified`.
- `theme.css` (U10): `body.mode-original .topbar` and `body.mode-original .tabs` get a warning border/background from `--warn`; `.tab.practice-modified` an accent underline; `#practice-bar` layout (hidden with `[hidden]`); `.diff-host` size inside the dialog (min(92vw,1400px) × 70vh).
